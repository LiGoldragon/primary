Security and state

Trusted-local—not a hostile-agent boundary.

Inside the experiment

  • Same-user Unix sockets
  • Broker identity and delivery metadata
  • Worker ID, unit, lease, readiness, exit
  • Coordinated, immutable Nix pins
  • Previous Home generation as rollback

Outside the experiment

  • Remote gateway, TCP, SSH, or tunnels
  • Messenger and Orchestrate sockets/state
  • Message payload collection
  • Automatic psyche or awareness logging
  • Blind deletion of broker PID/socket state
The system can coordinate trusted agents under one user. It should not be presented as protection from a malicious peer.
Upstream trusted-local model; local checks reject configured remote topology. Current source still contains a local remote-gateway socket capability, so remote use remains deliberately disabled.
