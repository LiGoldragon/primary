# Trait-First Redesign Directive — 2026-08-07

Ruling from the psyche while commissioning the Codex startup prompt.

## Ruling: imagined from-scratch traits are the redesign guide

Psyche: tell Codex "to mentally imagine the traits he would use if
tackling a problem from scratch, and using that as a guide to help him
delete and rewrite the non-optimally designed parts (anything old or
not using an obviously well designed trait). *value well designed
traits*"

The method: before touching an area, design in the mind the trait set a
from-scratch solution would use. That imagined trait set is the
measure. Whatever the existing code does that does not sit under an
obviously well-designed trait — anything old, anything trait-less,
anything under an awkward trait — is a candidate for deletion and
rewrite against the imagined set.

This extends the standing doctrine: traits are always the first pass
(traitStandardAndSpiritRename-2026-08-01, Ruling 3b), traits are the
code ontology, defaults whenever expressible through required
sub-traits (traitVocabularyRulings-2026-08-07), and the redesign
license and duty to subtract and replace
(SpiritIntentVisionGradation-2026-08-05). Well-designed traits are an
explicit psyche value, emphasized.
