# Ethos/Dotos Division of Labor; Help Emits Anatomy — 2026-08-02

Agent text answered: the session's agent-confusion mitigation discussion
(training agents on the syntax rules).

Psyche ruling [psyche-verbatim, condensed]: Ethos and Dotos are "the two
main syntaxes most agents will face; one specifies the types, the other
fills them with data — hence why the basic 'cli help' for their dotos
objects is meant to emit the ethos syntax that describes their anatomy."
The manager was directed to write the explanation of the two syntaxes'
peculiarities.

Seated:

- **Division of labor**: Ethos specifies types — the anatomy. Dotos
  fills them with data — the instances. The same delimiter vocabulary
  appears on both sides, surrounding types in Ethos and values in
  Dotos.
- **Help emits anatomy**: the basic CLI help of a Dotos-speaking object
  emits the Ethos declaration of its types. Documentation is not prose
  about the data; it is the type, shown in the type language. An agent
  learns what data to write by reading the Ethos that types it.
