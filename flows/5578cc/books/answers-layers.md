# Your answers on layers, and the two still open

You commented on «Layers, not models, in the skills» and «May Field speak to Psyche?». Here is what each comment set in motion, and the two things still waiting on you.

## What you decided

> Yeah let's make it four layers and we can make the quaternary layer be equivalent to Sonnet low effort and Luna low effort in the two different stacks.

> Yes I like layer.

> Let's make sure that all the skills refer to layers and there would be a skill that makes a correspondence of layers to models in the knowledge type skill.

Four layers, Primary to Quaternary, twelve voices. "Layer" replaces "rank" everywhere. Skills name layers, never models. A knowledge skill says which model holds each layer. All of this went to Mind Astra with your words, and the Flow design already uses `Layer.[ Primary Secondary Tertiary Quaternary ]`.

> Yeah I think that this is a great question because it brings up the fact that we're moving these skill variables into knowledge-type skills. I also want curriculum to support generating skills from more than one source for any type …

The skill-variables file becomes knowledge skills, and Curriculum learns to build each kind of skill from several sources, yours and other people's. This also went to Mind Astra.
