01 The whole, one pass

A request leaves the living as text and comes back as text; in between it is never text again. The CLI is the only part that knows datom, the Nexus the only part that knows the store. Each box names the repository it lives in.

The ordinary socket path shown is the one witnessed live: $XDG_RUNTIME_DIR/orchestrate-nexus/orchestrate.sock, mode srw-rw----. The meta socket on the same host is meta-orchestrate.sock, srw------- — not the name the executable's defaults carry. That divergence is §7 below. §0.2, §3.2

02 The ordinary signal ethos

The wire contract for any authenticated peer, whole. It is also the CLI's help text: orchestrate with no arguments prints this file, then the client ethos.

; Orchestrate Lock signal — the ordinary wire contract.
;
; The Lock family: acquire, release, observe coordination locks.
; Every lock carries an integer id, a name, a flow, absolute paths,
; and a reason.
;
; Observe opens a subscription rather than answering once. The Nexus
; writes one Observed frame carrying the state on open and one more
; for every later change, on the same connection, until the peer
; closes it. The subscription is the connection, so there is no token
; and no Unwatch: a peer that stops reading has unsubscribed. Every
; other query is answered with exactly one frame.
;
; Configure is accepted here only while the meta Configure has never
; been done. The receipt carries that fact, and once it is set this
; surface answers ConfigurationRefused.MetaConfigureOccurred.

05 Inside the Nexus

Start sequence. read defaults → open the store → build a two-worker multi-thread Tokio runtime → TransportRuntime::bind(configuration, store) → print orchestrate-nexus ready → serve_until(Termination::asked()?). Two workers because "the core is one actor and its durable step is synchronous, so one worker runs that step and one keeps accepting while it does". Zero arguments are enforced: if env::args_os().nth(1).is_some() { return Err(DefaultConfigurationError::StartupArguments); }, with #[error("accepts zero arguments")]; XDG_RUNTIME_DIR is required and relative paths are refused. main.rs:8-31 · defaults.rs:30-33,95-111

06 Observe today versus designed

The subscription is implemented on the server and truncated at the client. The Nexus half satisfies the design exactly; the CLI half ends at the state on open.

The CLI states its own reason at the site: "Exactly one reply is read even where the Nexus would go on writing — an Observe opens a subscription there. A CLI that takes one argument and prints one value ends at the state on open; dropping the connection is how it unsubscribes." The orchestrate skill already records the consequence. crates/orchestrate/src/main.rs:152-157 · .claude/skills/orchestrate/SKILL.md

observed No handshake, no contract identity on the wire

At the pinned signal revision nothing precedes the Query frame. signal/src/lib.rs:9-10 says so directly: "The protocol layered on top of the rkyv archive is not decided; nothing here anticipates it." The files at that revision are frame.rs, portable.rs, taxonomy.rs, transport.rs, generated/ — there is no accord.rs and no exchange.rs. The only thing preceding the first query is the kernel-level SO_PEERCRED check, which puts no bytes on the wire (and on the meta socket may put one PeerRefused frame there before any query is read).

Beside it: "Signals cross the network through a router. The router tells signal types apart by an enum that wraps the objects, held in the signal repository… That repository also holds what every signal needs in common — the handshake payload among it." (Vision/nexus.md:66-72) and "The protocol is to be decided." (Vision/signal.md:40-43).

inferred the socket is today's only discriminator between the two contracts, so a router would need that wrapping enum, which does not exist. in flight, not deployed the dirty signal-orchestrate/src/lib.rs adds impl signal::Contracted for Query { const CONTRACT_SOURCE: &'static str = ETHOS; } with the comment "two peers built from different sources refuse each other rather than negotiate — there is no version range, no minor tolerance and no compatibility path", and the local signal checkout at 66e7b153 carries accord.rs and exchange.rs.
