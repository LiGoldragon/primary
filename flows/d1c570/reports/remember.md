ethosic / logosic / nomosic), compositional. Going down, density and strictness; going up, visibility.
Each step converts into a wholly different type and nothing of the previous step survives. **Every
layer carries its own context**: the extent is protos's, the path is the datom's, the budget is the
reader's, the composition carries none. **No site, no situated pair.** **Five delimiter pairs**:
`{ }` `[ ]` `< >` structural; `« »` opaque; `( )` reserved for Meaning, read by balance. The curly
quotes are not delimiters. The key-value map is dropped entirely. The text type is `String`; the word
is **error**, not fault. Multi-pass over single-pass. Canonical print spaces the delimiters, never
inside guillemets.

**Kinds** are borne by the type converted and named for the layer it becomes: text `Protosizable`;
`Protos` `Textualizable` and `Datomizable`; `Datom` `Protosizable` and `Composable`; composition
`Datomizable` and `Compositional` (which states `ARITY` and `from_positions`). **Signal is parallel**,
not a layer.

**Datom** is a form at a path: `Datom { path, form }` with
`Form::{Struct, Vector, Variant, Bare, String, Meaning}`. Two string forms — bare and guillemets. The
dot is the separator and opens the body's delimiter; a head is always a variant and is capitalized;
`Observed.Locks.[]`. Position decides meaning. The datom composes; the type states its positions.
**Any Rust type bears the kinds through a derive in datom-codec with no attributes**, because datom is
structural all the way down. Containers bear the kinds generically. Errors name the layer and the path.
**No map**, with the technical argument written out. **Meaning** is the structured string, parentheses
its delimiter, read by balance, postponed to a plain String for now.

**Ethos** is the schema language. **Roots: Library, Signal, Sema.** No version in a file. The sweet
form (head, then sections as siblings) is converted mechanically to the canonical braced form before
the reader sees it. Sections: Library = imports, types, kinds, associations; Signal = imports, queries,
responses, types; Sema = imports, record types. **Declarations turn into Rust types with named
fields**, snake-cased from the type, constructed type-first (`string_vector`, `lock_option`), repeated
types as `first_`/`second_`. Inline types get an underscore-bearing derived name. A variant named as a
defined type carries that type. Every declared type bears `Datomizable` and `Compositional`; an alias
inherits. **The datom kinds are compiled in only where text is spoken** — a feature the CLI enables and
the Nexus does not. Kind identity is name plus constraints in one head. Simple kinds open with a
bracket, complex with a brace; the receiver sigils are `.` self, `!` mutable self, `:` no self.
Associations generate a compile-time assertion; bodies are hand-written. No tuples.

**Nexus** is the whole long-running component; Nexus is its name, daemon is not; a Nexus is *like* a
daemon, said only so a machine that thinks in daemons understands. Every component built from now on is
a Nexus. At least two sockets, the meta one privileged; one datom-converting CLI per socket; **the meta
CLI is `component-meta`**. Signal only; a Nexus never textualizes. Vertices and edges, one contract per
edge. Configuration: no arguments, no bootstrap binary, a built-in default constant, the Sema database
at the default location, Configure over meta, the first-configuration record reversed only on meta.
Three repositories per component. Kameo actors, standards undesigned, Arc-Mutex permitted.
**Observation by subscription; polling forbidden.**

**Signal** is portable rkyv plus a protocol; `Vision/signal.md` still says *"The protocol is to be
decided"* — **but signal 7.0.0 now implements one** (exchange ids, contract digest, handshake,
`Dispatch`/`Delivery`, `ExchangeLedger`), decided by a flow under the general "use common sense"
authorization. **Sema** is the database engine, authored in Ethos, root `Sema` declaring record types,
the rest to be decided.

**What is realized vs. what is only written:** protos/datom-codec/ethos-zero/signal are rewritten,
audited four times, and match the Vision closely. Orchestrate 0.35.0 is a Kameo-actor Nexus with two
sockets, peer checking, subscription, Configure lifecycle and store identity by device+inode — **and
has never been deployed**. Lojix 6.0.0 is deployed and serving. `nexus` is 0.5.0 and holds
configuration, situation, authority and relocation — not an actor or dataflow ontology. **No Nexus
ethos, no Sema ethos, no ethos repository, no router, no wrapping enum, no handshake payload exists.**
