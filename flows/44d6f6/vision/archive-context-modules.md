## Every change goes through him or a mechanism; lines are richly annotated

Context: book comment on the word "context" in a proposal about context modules (Checkouts, ownership and quotes, 2nd edition). He said he tends to tangent when commenting.

"there would be no context module change that would not go through me or through a mechanism. In the long term we could design some mechanisms to make sure that things could land without my review but would go through some kind of extensive automated machine review mechanism based on a number of standards and things.

I really want to push the idea of annotating these lines: these context modules are too different to be treated all the same. There are phrases in there that are in a completely different category from other phrases. They're all sharing the same context modules and they're all basically given the same weight because we're not richly annotating.

We need to go to even the separation of the context module types, like vision, intent, and so on. Like I said, now we'd like to review everything. This is a form of annotating the context by separating it into different types and then explaining what these different types are. It's a form of annotation but it's too crude for what I really want to do."

-- psyche, STT, book comment.
