> I like terseness, I like to the pointness. To me it's more like a programming user interface, reviewing skill changes, basically, and a proposal and visuals. I want visuals in the skills. I want code in the skills. It's basically our programming. That's how we program the machine. We use these modules essentially as our user interface for a human.

-- psyche, STT, 2026-10-07. Context: he had just commented on a book about spirit, a new kind of skill.

> If something is proposed or reviewed, it's in terms of skill and then we have this: the result of those skills that we look at. If we create a skill to visualize the state of the system or to visualize the state of transcript size on the machine, and if we have proposals for how to archive and how to save space, then we create skills for how we want that done as simply, tersely, and to the point as possible. The few knobs here and there, like which frameworks we use and how, all go at different layers.

-- psyche, STT, 2026-10-07.
