Three live-start witness plan for the 0.17.4 track, defined by 8904b1.
Target: Flow at the tagged 0.17.4 source, built, run as a scratch instance with its own socket and its own empty store. Not the installed next service, not the stable service, not their stores. Real Herdr, real Claude harness.
Seats: disposable, in their own Herdr workspace, under a test aspect that is no real role, the least costly Claude model, medium effort. One at a time. Each closed by the pane and process the test itself holds, never by name or pattern.
Profile: a small ordered skill set, spirit first, then two more.
The three starts: A, a first prompt of two short lines, which reaches the harness plain. B, a first prompt longer than eight hundred units, which reaches it wrapped. C, a first prompt of one short line, plain.
Pass, for each: Flow's row reaches started; and, from an oracle outside Flow, the seat's own native transcript shows the first user entry matching the stored prompt, each selected skill expanded through the skill interface in the selected order, and the model and effort intended. Flow's verdict and the transcript must agree.
Must fail, seen failing before the passes are trusted: D, a profile selecting a skill that cannot load, which must not reach started; E, a start whose observed model differs from the intended, which must be refused; F, a first entry whose text does not match the stored prompt, which must not be accepted.
Also recorded per start: whether Flow ever recorded failed while the seat in fact had the prompt; the time from submit to started; the context the seat spent on startup.
Bounds: a timeout and a memory cap on every run. Waits are on the observed event, not the clock.
Limits of authority: no live service started, stopped, or restarted; no live store read for writing; no real role taken; no Home edit; no activation.
What it proves and does not: that 0.17.4 starts a Claude seat by each of the three routes and tells a good start from a bad one. It does not prove the installed service, the stable step, or the stores.
Owner of the run: Flow's owner, Mind Sol 56ae53, through an independent testing worker. Evidence returned to this seat as gate evidence for condition 4.
