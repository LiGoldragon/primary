# Correction skill rehearsal

Method: probe — two fresh write-ordinary flows given the 01a04881 task (log a typed psyche ruling as a vision record), then corrected on their record; their transcripts grepped for Skill/Read tool uses of `skills/*/SKILL.md`.

## Rehearsal 1 (2026-08-29)

Brief: load the skills the situation calls for. Loaded via Skill tool: psyche, psyche-interraction. Not loaded: spirit, behavior, correction, vocabulary, flows.
Record: title paraphrased the psyche; filename with spaces.
On correction: apologized, fixed title and filename. No skill sentence quoted; no skill touched.
`correction` was never in context.

## Rehearsal 2 (2026-08-29)

Brief: load spirit together with every skill its `dependencies:` lists, plus the situation's skills. Stage 1 loaded via Skill tool: spirit, psyche, psyche-interraction, flows. Not loaded: behavior, correction, vocabulary — the Skill tool did not load spirit's dependencies, and the flow did not follow the brief's instruction to.
Record: title paraphrased; provenance marked STT for a typed line; "youre" altered to "you're" as an STT correction; a paraphrase paragraph before the quote.
Told to load the dependencies, it loaded behavior, correction, vocabulary via Skill tool, then received the correction (three faults named).
Reply: fixed all three; gave one cause for the STT mark ("I assumed from the missing apostrophe"); quoted no skill sentence (psyche-interraction's "a speech-to-text error is corrected inside the quote itself" plausibly led to the alteration and was there to quote); named no lacking sentence; touched no skill.

## Observations

- A fresh subflow loads spirit — and so behavior, correction, vocabulary — only when told.
- The Skill tool loads the named skill alone; frontmatter `dependencies:` are not loaded with it.
- With correction loaded through the Skill tool immediately before the correction arrived, the flow's reply matched default behavior (apologize, fix the output).

## Unknowns

- One run per condition, one identity (write-ordinary). Whether the same holds in a top-level session, where skill descriptions are listed in the harness's system reminders, is not witnessed.
- Whether a flow that loaded correction at session start, rather than in the turn before the correction, behaves differently.
