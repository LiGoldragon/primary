# design practice

## 2026-09-08 — machines think in code; talk to a machine about code with the code, so the next machine reading it understands

Answering a distillation proposal that described inline type declaration in prose, without code:

> When you say a type, maybe declare where it is used. You talk about inline type declaration, but you're not even giving me any example code, which is kind of absurd. Machines think in code, and I don't know why you would talk to a machine about code without giving him the code. Why don't you just redo all of that with some example code for everything, so that at least I can see you understand, and then we can expect the next machine to read this to actually understand?

-- psyche, STT.
