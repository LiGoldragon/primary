- **Joining.** Each machine joins by a small declared start-up step. It reads a one-time join key (a *preauth key*) from an encrypted secret file, without ever putting the key on a command line. The login address comes from cluster data, and the step runs only when the machine needs to log in. There is one reusable key per host.
- **Membership.** Membership is unchanged: ouranos and Prometheus, plus the declared test VMs.
- **Reset.** ouranos's hand-set login may be force-reset. Nothing depends on it.
- **Secrets.** A Field agent (b7da5d, "Field Sol") mints the secrets on ouranos as root and pipes them straight into the encrypted file, so no agent ever sees them. Seen: root on ouranos is reachable by key without a password. da88cf read your "get it fixed … best judgment" as the permission that the earlier plan said it needed.
