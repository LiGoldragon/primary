# Memory: rulings

Summary of the proposals in `5-memory.md`:

- 1 `Vision/memory.md` What memory is: the keeping part, declared under the Memory root, one memory per Nexus.
- 2 `Vision/memory.md` What memory never holds: no other Nexus's records, no Markdown configuration, no pane-title state, text only by choice.
- 3 `Vision/memory.md` Memory is reached only through operation: signal, operation, memory, operation, signal.
- 4 `Vision/memory.md` A memory schema is written in ethos: imports and record types; typed change; the edit carries the upgrade.
- 5 `Vision/memory.md` The store: one file through the memory engine; Datalevin for the Clojure prototypes, not ported.
- 6 `Vision/nexus.md` Configuration: "its Sema database" becomes "its memory".
- 7 `Vision/flowNexus.md` new Flow's memory: the context-module registry and one configuration per role, changed over meta.
- 8 `flow/crates/flow-nexus/ethos/memory.ethos`: Flow's Memory root with Module and RoleConfiguration, generated by build.rs.
- 9 `flow/crates/flow-nexus/src/store.rs`: module and role-configuration tables of the generated types, each Memorable.
- 10 `Curriculum/skills/vision-nexus.md`: memory reached only from Operation.

## Rulings

1. The keeping part's name.
   (a) Sema, the database engine, its root declaring record types: 2026-09-09, 564f55; 2026-09-10, fe34eb; `Vision/sema.md`.
   (b) Memory, Sema going to the meaning language and storage disliked: 2026-09-26, b7ba00; 2026-10-02, 91ea9f; ethos-zero since 15.0.0.
2. Whether each part of a Nexus has its own ethos root.
   (a) Signal and Sema give all the main types, the nexus-core concept dropped: 2026-09-10, fe34eb; `Vision/ethos.md` Roots.
   (b) The three layers, each described in ethos: 2026-09-13, 024bc7; 2026-10-02, 91ea9f.
3. The store engine.
   (a) Every Nexus opens its Sema database at the default location: 2026-08-26, 01a03d6e; `Vision/nexus.md` Configuration.
   (b) The Clojure tools keep a Datalevin database: 2026-09-25, e51411; 2026-09-26, e167d8.
4. Where Flow's memory lives.
   (a) In Mind, which grows the largest database: 2026-09-17, 9993b5.
   (b) In Flow's own database and memory: 2026-10-03, edf227.
5. The direction of a record type's upgrade.
   (a) Upgrade from the predecessor, upgrading the past: 2026-10-02, 91ea9f; sema-engine 0.18.0 `UpgradeFrom`.
   (b) Possibly symmetrical, from and to: 2026-10-02, 91ea9f.
