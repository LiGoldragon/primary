# Entry point: scratch workspace sources
Scratch workspace of the book «The standard entry point: three actors, one path», measured 2026-10-04.
`nexus-entry`: ways (a) typed handles and (b) the standard entry point, with kameo 0.22 and tokio 1; its `nexus_entry::main!` macro is one line.
`chronos-toy`: Chronos on (b), with four files generated by ethos-zero 16.0.0, datom-codec with rkyv, and redb 4.3.0; binary `chronos-nexus`.
`chronos-generated`: way (c) written by hand in the shape ethos-zero would emit; it carries a round-trip test.
Built and tested with rustc 1.97.1: `cargo build --workspace` and `cargo test --workspace --offline`; all tests pass.
`chronos-toy/tests/one_query.rs` sends Locate, Place, Locate through one door on a redb file in a temporary directory.
The `compile_fail` doctests in `chronos-toy/src/lib.rs` and `chronos-generated/src/lib.rs` hold the signal-side reaches for memory.
Left out: every `target/` directory (about 649 MB with it) and any file over 1 MB; none of the sources was over 1 MB.
`chronos-toy` depends on datom-codec by path at `/git/github.com/LiGoldragon/datom-codec`, so it builds only where that exists.
