## Choices this build made where the spec gives none (this flow's inference)

- **The refusal is raised in checking, not in conception.** The registry travels on `Scope`. The spec allows "conception or checking" for 6d-6f but names conception.rs:408 and :439, which take no registry input. The observed paths are still the head's.
- **`Check` carries the registry through the same channel as `Generate`.** The spec places the refusal in conception, which `Check` also runs. Without a registry, `Check` would accept what `Generate` refuses.
- **An entry whose emission is not a Rust path counts as unregistered.** Such a source is refused as `Source.<name>`, the same as a source with no entry.
- **6e: `Check` ignores the assembly file's target.**
