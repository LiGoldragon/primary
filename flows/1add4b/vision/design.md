# Design

## 2026-10-31 — Simplifying without adding code, or removing code while behavior improves, is always good; it is the sign that something good was done
Context: the living, in the Psyche core Primary chat 1add4b, same message as the Flow Nexus version 1 refutation, setting the night's upkeep.

If you can improve the readability and simplify stuff by removing code while improving the simplicity and modularity of it, that's good. That's a good sign. If something behaves better and it runs with less code, then that means something good probably was done. Anything that either simplifies without adding more code total or even removes total code is always good.
