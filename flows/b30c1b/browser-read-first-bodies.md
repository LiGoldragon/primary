Interface draft: installed sibling browser-read takes ONE user datom argument `Read.{ PageName [ FieldName ... ] }`. Package internally supplies sibling playwright-chrome path. Runtime registry resolves to `$XDG_CONFIG_HOME/browser-read/registry.datom`, or `$HOME/.config/browser-read/registry.datom` when XDG_CONFIG_HOME is unset/empty. Relative XDG path currently resolves through path.resolve; this choice is visible and unreviewed. Missing/unreadable/invalid registry refusals name the exact resolved file path.

Registry draft: `Registry.{ { NavigationMilliseconds ActionMilliseconds CommandMilliseconds OutputBytes } [ { PageName Address [ { FieldName Locator } ... ] } ... ] }`. Four limits are required positive safe integers supplied by Field; no authored entries/addresses/locators/default limits. Page names and per-page field names are nonempty unique strings; address must parse as HTTP(S). Each field has exactly one locator and returns its found innerText, including empty text. Request fields are nonempty/unique; duplicate/empty/malformed request currently maps to InvalidRequest. Requested order is preserved.

Output draft: `Values.[ { FieldName Text } ... ]` or typed `Refused` variant, status0 only for Values. Refusals: InvalidRequest; MissingRegistry.Path; UnreadableRegistry.Path; InvalidRegistry.Path; UnknownPage.Name; UnknownFields.Names; Browser; MissingFields.Names; Navigation; TabOpen; TabCleanup; WrapperLifecycle. MissingFields aggregates every missing/ambiguous/failed extraction and returns no partial values. Datom quote escaping and schema-bound decoder are implemented locally for strings/structs/vectors/root variant; generic Datom compatibility is not claimed.

Transport choice: existing saved-token wrapper `--json -s=<private UUID> attach --extension=chrome`, generated fixed run-code function, then detach, with private temporary working/config/output directory. Caller/config never supply JavaScript. The generated function creates one tab, navigates and reads configured locators, and closes that tab in finally. It never closes existing tabs or uses a model. Parent filters JSON to requested values/refusal and suppresses raw CLI stdout/stderr. Existing CLI snapshot capture remains an internal transient artifact; this is NOT snapshot-free transport. Temporary artifacts are removed after detach; cleanup or detach failure overrides values with typed refusal. Token local URL/argv is explicitly accepted under ydz5; no transport rewrite or new Allow.
