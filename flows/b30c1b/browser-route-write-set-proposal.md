## Minimal semantic boundary to settle

- Signal: ordinary typed page-name plus requested field names; owner configuration operation for page address and named extraction definitions. Exact schema/version, duplicate/empty-field handling, authentication and request/reply correlation remain design questions. No token or raw page body belongs in a request.
- Operation: validate configured page/fields, use the approved Field-held browser capability, select only requested values, return success or explicit typed refusal. No model and no account mutation in version1; direct fixed-wrapper use remains available to Field for unknown pages, with discoveries later configured as registry entries.
- Memory: Field-owned runtime registry is the configuration authority. Exact persistence/owner socket and whether an existing Nexus holds it or a new Nexus is required are unresolved. No Home registry/account defaults, copied credentials, raw browser state or cached account values are proposed.
- Emission: requested named values only, or typed refusal. Exact value types, partial-failure/atomicity, output codec, limits and diagnostic redaction require ruling; no snapshot/page/token dump or invented field is a result.
