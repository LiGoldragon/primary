## 2026-10-28 — What describes an Ethos is another Ethos; a comment adds what is still needed
Context: the living, direct to Psyche core Primary 7459f3, on vision-ethos comments, after the Primary said a comment belongs where the name leaves something unsaid; relayed by that Primary.

> The thing that describes another thing is another ethos. In a way it’s better to write the code that specifies the object that we’re looking at first and then if more information is needed we can use a comment.
