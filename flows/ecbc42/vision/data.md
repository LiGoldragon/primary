## No data in a Rust code repository

Context: on roles.datom living in the Curriculum Rust repository; the living ordered a full audit.

"This should be enforced now so we stop recompiling an entire fucking codebase every time we change data that is fed into it, which is fucking ridiculous. ... 

There should be absolutely zero data other than the data needed to compile the code (which is like the cargo file and stuff) in any Rust code repository. All the data has to be taken out. If you don't know where you can create a `-data` suffix version of the same repository, or a config or whatever best suits it, or another repo that is suited to hold that data.

Data can never live with the Rust code, other than, like I said, the data needed to compile it (like the Nix code and the Cargo code and things like that: the build, the building data, nothing else)."

-- psyche, STT.
