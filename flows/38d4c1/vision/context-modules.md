# context-modules

## A word with a module of its own is defined there, not in the vocabulary

Context: book comment on Great advancements, 2nd edition, on the proposed vocabulary line "For now, Mentci is the daemon through which the living interacts with the system, and Unity is its interface."

"I can approve the words but I think we can approach this with a better structure since these very topics will need context modules of their own. ...

let's look at the list of vocabulary and find anything that either already has a context module dedicated to it or, since it's a big enough topic, could have a dedicated context module for it. By virtue of how the skills are injected into the harness after the context modules are transformed into them (or even if they were put in the system prompt), the words themselves and their description would usually be the first thing either in the definition or at the beginning of the context module: explaining what this concept even is. This would make the entry in the vocabulary both redundant and problematic in the sense that if we change anything now we have two places to edit.

I would refuse this as it is but suggest that we just propose these words and any other words that could be in a dedicated module to have their own dedicated module proposal."

-- psyche, STT, book comment.

## Knowledge is what is effective now; what should be is vision

Context: book comment on Lean flows: a lean launch, 2026-10-22.

"Your Lean Flow presentation, what is it? Lean Flow is a Lean launch. There are parts in there that are really vision."

"When you say "in the long term," that's not knowledge. Knowledge is effective right now. If you say "for version 0.39," unless that's the deployed version or unless you specify that this version is not deployed, it's not knowledge. You should specify which version is currently deployed. Anything that isn't current in the system is not knowledge or anything that isn't specified to be in a version that is not the default version is not actually knowledge."

-- psyche, STT, book comment.
