The translator is the text-handling of the CLI broken out into a component every Nexus can use. It is not a Nexus: no domain, no Memory. The translator makes the system call, so a Nexus never types herdr; the CLI is a shim that sends its argument to the translator and waits for the reply.

What the translator is

The translator is the component that carries data between datom text and signal, both ways. It holds the codec; a Nexus holds none. Several Nexuses and the CLI share one translator, built against their contracts; a new set of contracts is a new translator, named apart by a random suffix.

The way in

The datom socket's signal:

Signal
[ translator:[ Request Answer Error ] ]
[ Relay.Request ]
[ Relayed.Result<Answer Error> ]
[]

In, the CLI's one argument:

Relay.Flow.Launch.{ { Psyche core Primary }
                    Predecessors.2
                    «Design the translator» }

Out, the CLI's reply:

Relayed.Ok.Flow.Launched.7

A text that fails names the layer that refused it and the path of the datom where it did:

Relayed.Err.{ Compositional [ 0 1 ]
              «Predecessors.x: x is not an integer» }

The way out

The translator starts the subprocess: it is the one place that knows what a Prompt is in this world. An output a Nexus wants textualized and returned is asked with Textualize.

The signal socket's signal:

Signal
[ translator:[ Answer Text Error ] ]
[ Textualize.Answer
  Emit.Answer ]
[ Textualized.Result<Text Error>
  Emitted.Result<Done Error> ]
[]

In, from the Flow Nexus, as signal:

Emit.Flow.Prompt.{ 3 { { Psyche core Primary }
                       Soft.Question.«Ruled?» } }

Out:

Emitted.Ok.Done

The library

Request and Answer have one variant per Nexus, carrying that Nexus's own Input or Output, so a text names its type by its heads.

Library
[ :flow:[ Input Output ]
  :orchestrate:[ Input Output ] ]
[ Text.String
  Request.[ Flow:flow:Input
            Orchestrate:orchestrate:Input ]
  Answer.[ Flow:flow:Output
           Orchestrate:orchestrate:Output ]
  Layer.[ Textual Protosic Datomic
          Compositional ]
  Path.Vector<Integer>
  Error.{ Layer Path String }
  Done ]
[ Emittable.[ emit.[ Result<Done Error> ] ] ]
[ Prompt.[ Emittable ] ]

The one hand-written body per output type:

impl Emittable for Prompt {
    fn emit(&self) -> Result<Done, Error> {
        let text = self.message
            .datomize(Path::root())
            .protosize().textualize();
        self.pane.send(text)
    }
}

Many translators

A Nexus is configured with its translator and discovers nothing; the suffix only keeps them apart.
