## Findings, ranked

1. **Misplaced anatomy (psyche's own finding; structural).** Both wire
   repos carry nexus.ethos and sema.ethos as empty documents (ledger
   decision 6), while the component's real engine operations and
   Sema-stored types (configuration, active locks) are authored in
   Ethos nowhere — orchestrate itself holds no Ethos source. The
   triplet was treated as a per-repository file set; the ruled anatomy
   places wire types in the signal repos and the component's nexus and
   sema Ethos with the component. The generator's component model
   embodies this: it realizes exactly three sources per consuming
   repository, forcing empty nexus/sema in wire repos. Recorded in
   vision/ethosSourceFiles.md.

2. **Unsupported-boundary claim overstated.** The ledger (decision 7)
   and log claim imports, interactions, unconstrained generics, and
   streaming "remain explicit errors." True for imports-in-signal and
   unconstrained generics; interactions are structurally unexpressible
   but yield no named error; imports in nexus/sema are silently
   ignored; populated stream sections are emitted, not rejected.
   Harmless for the two actual contracts (empty streams), but
   silent-ignore is hidden partial behavior in the very place the flow
   claimed none.

3. **One tuple-rule violation.** `OrchestrateStore::open` returns
   `(Self, Configure)` — a designed tuple in authored runtime code,
   not a dependency contact point. All other tuples sit at contact
   points; generated code has none.

4. **Trait-sparse authored runtime.** The fresh orchestrate runtime
   has 7 bare impl blocks (~25 methods) against 2 trait
   implementations; the two transports share identical method shapes
   with no common trait. Generated code has strong trait coverage.
   POC latitude covers making the choice, but it was not recorded as
   an open bit in the decision ledger.

5. **Durability nuance.** Persistence across store close/reopen is
   unit-proven; the live scenario never restarts the daemon.

Not exercised, correctly: carrying declarations and the approved
const fn-pointer checking mechanism — the psyche scoped trait syntax
out of the MVP; the Ethos sources define Interface types only.
