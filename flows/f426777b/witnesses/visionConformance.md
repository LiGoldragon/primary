## A4: Ethos non-repetition and Datom syntax (CONFORMING)

Ruling: Vision/ethos.md

> Any repetition in ethos syntax is an implementation failure. Ethos aims to be the most terse, non-repetitive syntax ever made.

Ruling: Vision/datom.md

> The dotted prefix of a delimited block is part of the block's type; its official name is Head; a variant always re-emits its Head when textualized.

> [parentheses] are the default string delimiter, balance-based

> A string is written bare whenever the bare form can carry it

Method: code read signal-orchestrate ethos/signal.ethos, meta-signal-orchestrate ethos/signal.ethos
Method: code read generated signal.rs DotosEncode and EthosValueEncoding implementations
Method: code read orchestrate CLI source for Datom text acceptance

Observations (non-repetition):
- Each type declared once. Struct fields are positional references to declared type names without restating shape. Enum variants listed once. Channel identity appears once per interface.
- Operation names like `PathLockRegistered.PathLockRegistered` are not repetition: the operation name (output section) and the type name (types section) are distinct semantic positions in the Interface dialect.

Observations (Datom syntax):
- Heads: `PathLock` struct emits `PathLock.{...}`, `PathLockName` scalar emits `PathLockName.value`, `PathLockRegistered` (one-field nested struct) emits `PathLockRegistered.{...}` with flattened inner body (no doubled braces). Variant heads re-emit correctly.
- Embedded non-repetition: The two-layer encoding (`DotosEncode` with head at outer contact point, `EthosValueEncoding` without head for embedded fields) produces the ruled `PathLock.{name [/path] (description)}` format. Inner types like `PathLockName` do not repeat their heads when embedded.
- Balance-based parenthesis strings: Description field uses `(description)` delimiters, consistent with the ruling.
- Bare strings: String fields emit bare when the bare form can carry the value, via the standard `DotosEncode` pathway.
- Map syntax: Not exercised (no maps in POC types).

Verdict: All four checked Datom syntax rules are conforming. Non-repetition is satisfied at both the Ethos schema level and the Datom text level.
