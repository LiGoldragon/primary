+ ## A belief module names no particular of his installation
+
+ A belief module carries the mechanism, and nothing that is true of one installation alone: no cluster name, host name, login, path or address of his. An example that needs a name uses one that is plainly an example, and says so. The particulars of his installation live in the host's own declaration, which the module points to.
+
+ ```nix
+ # a belief module's example: a name that
+ # is plainly an example
+ { cluster = "example"; host = "laptop"; }
+ ```
