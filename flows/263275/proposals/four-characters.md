### Proposal 2: A hash is four characters · psyche-belief › intent/energy.md

**Comment** Addition, at the end:

+ ## A hash is four characters
+
+ A thinking machine reads and writes a hash as its first four characters, which tell it from its neighbours; the whole hash lives in the tool that holds it, and one command fetches it from the four. This holds for every hash there is: a commit, a store path, a session, a flow, a generation, a deployment, an address.
+
+ ```text
+ Landed at XXXX.                 ; a commit, by its first four
+ Generation XXXX is live.        ; a store path
+ Successor XXXX took the seat.   ; a flow id
+ git show XXXX                   ; the tool resolves the four
+ ```
