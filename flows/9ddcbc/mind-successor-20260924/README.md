# Prepared Mind Sol successor packet

This directory is a launch-ready input packet. It does not record a launch.

`profile.json` is the human-readable typed profile. `startup-handoff.md` is
the recovery body appended after the complete current `main-flow` and other
startup-only role bodies in one first user prompt. It points the new seat to
the predecessor summary without copying its large identifiers or implementation
history. `launch-request.datom` is retained only as the superseded Flow request
from the prior plan and must not be submitted.

This is the living-authorized narrow direct-recovery exception: use the
already-proven next Codex endpoint for this one startup, truthfully not as a
Flow-mediated launch. No human types a launcher command. The first turn is
launcher receipt only. Identity, title, route, handoff, and later retirement
remain distinct witnessed stages. The first post-readiness job is delegating
the coherent Flow/Herdr/Home deployment; later refreshes return to Flow.
