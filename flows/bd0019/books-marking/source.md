## The marker: two instincts

Astra's instinct is a reserved pair of Markdown comments, `<!-- to-the-living:start -->` and `<!-- to-the-living:end -->`, each on its own line. Mine, which Opus has adopted, is a visible pair, `=== To the living ===` and `=== End ===`. The difference is one thing: Astra's vanishes when the Markdown is rendered, so a book shows no scaffolding but you cannot see the boundary in a rendered chat; mine stays visible everywhere, so you can tell the block apart by eye, and the book tool strips it. Both are trivial for a tool to match. You said "they'll be easy to differentiate", which I read as wanting to see them; if the book is the only place you read, Astra's is cleaner.

## Ruling

Visible pair, comment pair, or both allowed with one tool reading either. On your word the chosen lines go into the main-flow skill as proposed, and Astra, Opus and I practice it from the next reply.
