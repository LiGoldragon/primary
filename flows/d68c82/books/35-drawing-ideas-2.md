# Drawing ideas

```
 an idea to show
     |
     v
 +------------------------+
 | the machine describes  |
 | it as data: parts,     |
 | links, what matters    |<--+
 +------------------------+   |
     |                        |
     v                        |
 +------------------------+   |
 | code draws it in the   |   |
 | fixed colours          |   |
 +------------------------+   |
     |                        |
     v                        |
 +------------------------+   |
 | a model looks at the   |   |
 | picture: clear?        |---+
 +------------------------+ no
     | yes
     v

```

Five proposals. Each one says where it lands and carries every line it adds.

## Proposal 1: add to the vision of books

+ An idea reaches the living as a picture first. A figure shows one thing, where the idea has a shape, and its colours and marks mean the same in every book.

Ruling: land, amend, or reject.

## Proposal 2: add to the vision of books

+ A proposal is drawn as well as written: what it adds, removes and keeps, in one frame.

Ruling: land, amend, or reject.

## Proposal 3: add to the vision of books

+ A machine describes a figure as data, code draws it, and the drawing is looked at and mended before it is shown.

Ruling: land, amend, or reject.

## Proposal 4: a new module, the Illustrator's rules

+ Blue with a thick outline marks the one thing the living rules on.
+ Green with a plus marks what is added or works.
+ Red-orange with a minus marks what is removed, broken or a risk.
+ Amber with a question mark marks an open question.
+ Grey and thin marks context that does not change.
+ Purple, drawn as a person, marks the living.
+ Dashed means proposed; solid means it exists now.
+ A box drawn around things means they belong together.
+ A colour never stands alone: it always carries its sign.
+ One figure says one thing.
+ A figure is drawn only where the idea has a shape: a branch, a loop, a join, a comparison; a straight line of steps stays a sentence.
+ A box holds a few words; the verb sits on the arrow.
+ A figure has nine boxes at most; a bigger idea becomes a sequence of figures.
+ Amounts are drawn to scale.
+ A change is drawn in one frame: what is added, what goes, what stays.

Ruling: land, amend, or reject.

## Proposal 5: add to the rules for writing books

+ Every line a proposal would land sits inside that proposal, and the proposal's heading says where it lands. Nothing outside a proposal reads like one.

Ruling: land, amend, or reject.
