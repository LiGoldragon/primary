# Only real code

The examples in «The Ethos syntax» were written without ever being read by an Ethos parser: an enum with one variant, an ethos with no variant, forms mixed that cannot be mixed. No rule required a book's code to pass the real tool, and code in a proposed syntax had no parser to pass at all.

## Proposal 1: psyche-context › intent/design.md

+ Every code example is real code: whole, canonical, and accepted by the real parser or compiler. A fragment, a mix or an invented form is never shown.

Ruling: land, amend, or reject.

## Proposal 2: psyche-context › vision/book.md

+ A book's code is checked by the real tool before the book is published, and the build refuses code that fails.
+ Code in a proposed syntax is checked by a parser that carries the proposal.

Ruling: land, amend, or reject.

## Proposal 3: psyche-context › vision/ethos.md

+ Every type is shown with the traits that make it act. A type with no trait does nothing.

Ruling: land, amend, or reject.
