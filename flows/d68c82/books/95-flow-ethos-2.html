A simplified flow is a kind of flow made for judgment alone: it starts with a system prompt of its own, it has no regular tool, and its response is its message.

A flow is specified whole, in Datom, by a domain-specific language in Ethos: its system prompt, which is the whole base context; how it works; its default context modules; and its variations. The Flow controls the whole system prompt of every flow ethos holds theit starts. The specification, with its complete worked example, is vision:flow-ethos.

The simplified flow is one variant of the specification. It goes back and forth a few times with a supervising flow, which has the tools and finds out for it what it asks.

The main flow is the first vector's one entry. Its Address is Psyche, core, Secondary. It may run on claude-opus-5-5 or on the same model with the million context, at Medium effort. Five modules are composed into its system prompt, and none into its first user message, so its UserModules is the empty vector.

The subflows are the second vector's two entries. The book subflow may run on sonnet at Medium effort, is Unrestricted, composes five modules, uses Read, Bash, Agent and Artifact, and only the Psyche core Secondary metaflow may start it. The illustrator subflow is Restricted, has no tools, so its Tools is the empty vector, and Any flow may start it.

The simplified flow is the third vector's one entry, named fableDesign. It may run on claude-fable-5-1 or on the same model with the million context, at Medium effort, composes three modules, and answers to the Psyche core Secondary flow. It has no tools field.

Description
The missing Set in Ethos, a simplified flow's reply, where default modules live, how a variation overrides, which fields each variant has and where specifications live are unresolved.

Ethos has no Set

Finding, witnessed: ethos-zero 17.0.0 (pin 07714b0) refuses a library that declares Models.Set<Model>, answering Undeclared.Set; the same library with Vector<Model> is accepted. Ethos has no set: its intrinsic types are String, Integer, Decimal, Boolean, Meaning, Vector, Option, Result and Self. A flow's models are a set, in which order and a repeat carry no meaning, so every block of this book that writes Models.Set<Model> is labelled not yet parseable.

How is a set declared in Ethos and written in Datom? What would settle it: the specification of flow-ethos accepted by ethos-zero and decoded by datom-codec with Models.Set<Model>.

  • Alternative a: a Set intrinsic, written Set<Item>, its Datom a bracket as a vector is, refused by the reader when an item repeats. It touches the Ethos reader, the generation of Rust, and datom-codec.

Tools and the Only vector of Callers are sets in the same way.
