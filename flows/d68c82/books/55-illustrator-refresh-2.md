# Refreshing the Illustrator

The test was run again as you asked: the Illustrator started lean, with no tools and only its own instructions, and each way of continuing ran twice, once back to back and once with gaps of over an hour, so the cache ran out. A lean start is 1,366 tokens, where the harness's default start is 26,100.

| six figures for six books | back to back | gaps over an hour |
|---|---|---|
| starts fresh for every job | 0.28 dollars | 0.30 dollars |
| keeps one long conversation | 0.37 dollars | 0.65 dollars |
| compacts after three jobs | 0.35 dollars | 0.56 dollars |

A lean fresh start is now the cheapest either way, and an expired cache costs it almost nothing, while a long conversation pays again for all its earlier drawings. The quality was the same in every way of running.
