# Lean flows

A flow starts with tools and harness instructions it never uses, and each one costs on every request. The Illustrator needs a few tools; it was given all of them. Every part that can be taken out becomes a named module, so a role can leave out what it doesn't need.

## Proposal 1: psyche-context › skills/vision-flow.md

+ Every part of a flow's start that can be left out, a tool, a harness instruction or a harness feature, is a named module of its own.

Ruling: land, amend, or reject.

## Proposal 2: psyche-context › skills/vision-flow.md

+ A flow is started with a list of the modules it leaves out. Each metaflow role sets its own list, and a call can change it.

Ruling: land, amend, or reject.
