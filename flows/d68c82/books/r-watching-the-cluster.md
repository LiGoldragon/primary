# Watching the cluster

The cluster has no monitoring yet, and this book proposes the vision for it. This edition names the store by its role instead of a host, and moves the list of what is measured into Ethos, with short-term and long-term measures. The comparison of monitoring systems you asked for is its own knowledge book.

## Proposal 1: psyche-context › skills/vision-monitoring.md, a new file

+ Every host carries one light collector.
+ One store, on the node the cluster data names as the metrics store, keeps the measures and draws them.
+ What is measured is written in Ethos: each measure is first stated as a want, then a system is built to measure it.
+ Measures are held as short-term or long-term.
+ An alert reaches the living in a channel he can answer.
