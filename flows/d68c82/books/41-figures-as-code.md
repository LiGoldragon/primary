# Figures as code

A figure kept as a picture can't be read or edited by a text model. Kept as a few lines of data next to the words it shows, a model can write and read it, and code draws it the same way every time.

| form | models read it | drawing | on a phone |
|---|---|---|---|
| our own data form | written by us | our style | clean |
| Graphviz | best measured | plain | clean |
| D2 | not measured | prettiest | text too small |
| Mermaid | widely used | good | breaks in our books |
| hand-drawn SVG | worst | any | any |

Large documentation projects use Mermaid most. The one study comparing forms found models read Graphviz far better than SVG. Each form was tried here on the same figure.

## Proposal 1: psyche-context › skills/vision-book.md

+ A figure lives as data beside the words it illustrates, in the same source: what it shows, not how it looks. Code draws it on every build.
