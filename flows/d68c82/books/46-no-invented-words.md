# No invented words

"Seat" was a machine's word. It was rejected more than once, yet it stayed in the opening instructions of every main flow, and from there it spread into 27 modules. It is being replaced by "metaflow" everywhere today.

## Proposal 1: psyche-context › vision/vocabulary.md, a new file

+ A machine uses only words the living has used or the vocabulary defines. It never coins a word.

Ruling: land, amend, or reject.

## Proposal 2: psyche-context › vision/vocabulary.md, a new file

+ A book or message that uses a word the living has never used and the vocabulary does not define is refused before it reaches the living.

Ruling: land, amend, or reject.
