# The living's undistilled psyche, ranked by emphasis

Read on 2026-10-12. Raw records came from `flows/*/vision/`, `flows/*/notion/` and `vision-raw/`, leaving out `archive-*`: 3050 records in 1706 files. A record is one `##` entry, or a whole file when it has none. The landed psyche read was psyche-skills HEAD d0d194c: `skills/*.md` and `vision/ethos.md`.

How the counts were made. For each subject the gatherer hand-picked the records that carry it. "Records" includes relays: when the same words are logged in several flows, each copy counts. "(n)" is the number of distinct utterances, matched on the first 120 letters of the verbatim. A record's date is the first date in it, else the file header, else the file's first git commit. The ranking is this flow's judgment. It weighs records, days, flows, span and signs of frustration together; it is not a computed score.
