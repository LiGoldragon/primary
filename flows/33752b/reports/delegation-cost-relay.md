# Delegation-cost research, relayed (claim)

Source: Mind Tools Primary's research, relayed by d68c82 on 2026-10-13. Not witnessed by this flow.

- Five large single-read cases: a subflow cut the visible text in the main window by 94%. In small reads, direct reading wins once 300–1000 characters of envelope are counted.
- Break-even: delegate when call + result + avoidable output > brief + return + transport overhead.
- A real read-trivial child (Codex, Luna, low effort) started at 33.4k input tokens before doing anything, from injected startup context: a lean flow needs a lean prefix, not just a short brief.
- This seat's 408k context divided strictly: 73% noise, 19% adjacent, 8% relevant.
- No population ratio measurable yet. Needed: record each retrieval episode's brief, return and exact per-request usage on parent and child; compare direct and delegated paths on the same evidence.
