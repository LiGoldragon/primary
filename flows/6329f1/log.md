Rust: `pub type Text = String; pub type Integer = i64; pub type Decimal = f64; pub type Boolean = bool; pub type Symbol = Text;` `pub struct Potential<T>(Text, PhantomData<fn() -> T>)` with `From<Text>`. No single-field structs (e4a40e); tuple structs and tuple variants, as the ethos declares them; every method under a trait (Intent/mandatoryTraits); no free functions; fully qualified names in generated code.

Delineation rules (Vision/datom.md Syntax; e8c4cc61; 04db2fd2): a single `;` opens a comment to end of line. Whitespace outside opaque regions separates structures. Six delimiter glyphs: `{ }` `[ ]` `« »` (U+00AB/U+00BB) `< >` structural; `“ ”` (U+201C/U+201D) opaque to the closing `”`, every glyph inside content; `( )` opaque, read by balance, nesting counted, closing at the parenthesis that balances the opening one. A Bare is a maximal run with no whitespace and no delimiter glyph. Inside a run a separator (`.` `!` `:`) splits head from body when a non-whitespace, non-closing character follows: `Some.42` is Headed(Some, Period, Bare 42); `Reviewer.{` is Headed with an enclosed body; `a:b:c` is a chain. A separator followed by whitespace, a closer, or end of text is MissingBody; a run beginning with a separator is MissingHead. Extents point into the source text as given (no normalization pass; normalization is what print produces).

Canonical print (Vision/datom.md; ad19b1 "space the delimiters and the inner content"): `{ a b }`, `[ a b ]`, `« k v k v »` with one space inside at both ends when non-empty; `{}` `[]` `«»` when empty; angle tight, `<a b>`; `Head.body` with nothing around the separator; siblings one space apart; opaque regions verbatim with their glyphs; comments never printed; one line.

Incorporate (Datom → T), positional, the reader walks the expected type (Vision/datom.md De/serialization):
- Integer: Bare, ASCII decimal, optional leading `-`, no `+`, no leading zero except `0` itself. Boolean: Bare `True` / `False` (a symbol alone in an enum position is a variant; variants are capitalized). Decimal: a Bare or an all-bare Variant chain rejoined (`3.14` delineates as Headed(3, Period, Bare 14)); finite; datomize writes the shortest exact form with a `.`.

- Vector<T>: Vector of T. Map<K,V> (BTreeMap): Map; DuplicateKey faults. Option<T>: Bare `None` / `Some.<T>`. Result<T,E>: `Ok.<T>` / `Err.<E>`.
- A struct: Struct with the exact arity, each position its type. An enum: Bare(name) for a variant carrying nothing; Variant(name, Period, Some(body)) for a variant carrying data, the body being the payload's own anatomy with no extra head (`Reviewer.{ 2024 17 }`, `Observed.Locks.[]`, `Some.42`, `Locked.{ 442 … }`).
