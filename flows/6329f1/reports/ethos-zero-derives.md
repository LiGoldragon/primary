# ethos-zero derives and Meaning fix

Flow 6329f1, subflow ethos-zero-derives.

## Changes

### 1. Library types now emit Clone, Debug, PartialEq, Eq derives

`type_declaration_tokens` and `emit_variant_tokens` both computed a `derive`
token stream conditioned on `signal: bool`. When `signal = false` (Library
root), the derive was an empty token stream, so no derives were emitted for
Library structs, enums, or inline variant types.

Fixed: the Library branch now emits `#[derive(Clone, Debug, PartialEq, Eq)]`.
The Signal branch is unchanged (`Archive, RkyvSerialize, RkyvDeserialize,
Clone, Debug, PartialEq, Eq`). No `PartialOrd`/`Ord` are added; Signal
does not add them, and neither does Library.

### 2. Meaning intrinsic maps to datomic::Meaning (was datomic::MeaningValue)

`type_expression_tokens` had `"Meaning" => quote! { datomic::MeaningValue }`.
The type was renamed to `datomic::Meaning` in datomic commit `768426ea`.
Fixed to `datomic::Meaning`.

### 3. Fixture library gains a Meaning position

`fixtures/example-library.ethos` gained `Note.{ Text Meaning }` to witness the
Meaning mapping in a real fixture. The fixture round-trip test and the
`fixture_library_reads_and_emits` test both run on the updated fixture.

### 4. Generated self-bootstrap module regenerated

`src/generated.rs` is the output of emitting `ethos-zero.ethos` (a Library).
After the derives fix, Library types in that output now carry
`#[derive(Clone, Debug, PartialEq, Eq)]`. Regenerated by running the emitter
directly and writing the raw token stream (matching the `bootstrap_module_is_fresh`
test's comparison method).

### 5. Version bump: 1.1.0 → 1.2.0

Library type emission gained derived traits (public behavior change).

## Tests added

- `library_struct_emits_clone_debug_partialeq_eq_derives`: Library struct
  emits derive attributes without rkyv Archive.
- `library_enum_emits_clone_debug_partialeq_eq_derives`: Library enum same.
- `meaning_intrinsic_emits_datomic_meaning`: Meaning type maps to
  `datomic::Meaning` in emitted Rust.
- `fixture_library_meaning_round_trips_in_e2e`: e2e compile test with a fresh
  Cargo project that uses the emitted library fixture; asserts `(a meaning)`
  text in gives `Meaning::Plain`, and round-trips `Note(author, Plain("a meaning"))`
  to `{ author (a meaning) }` and back.

## Derive line for a Library struct

From `ethos-zero.ethos` (self-description, a Library), the Library struct type
emits:

```
#[derive(Clone , Debug , PartialEq , Eq)] pub struct Library (...);
```
