## Decisions

**Why hand-written Datomic for Query was not needed**: The recursive
`Box<Query>` in the Grep variant initially appeared to require hand-written
Datomic impls, since datomic provides no blanket `Datomic for Box<T>`.
However, `Box` is `#[fundamental]` in Rust, so `impl Corporal<Datom> for
Box<Query>` is orphan-allowed with Query as a local type. The generated code
from ethos-zero works unchanged; only the two Box<Query> impls (5 lines each)
are hand-written. This is the smallest honest workaround.

**Why the output changed to canonical datom**: The brief requires "every CLI
or edge takes one inline datom and prints canonical datom." The human-readable
block format is replaced by a datom vector of Answer structs, making the tool
composable.

## API deviations found

Recorded in reports/api-deviations.md under "port findings":

1. **datomic: no Datomic for Box<T>** — needs blanket impl. Workaround: local
   impl per concrete type.
2. **datomic: no Datomic for Situated<F>** — needs blanket impl. Workaround:
   manual datom construction.
3. **ethos-zero: Library types lack derives** — no Debug/Clone/PartialEq.
   Workaround: pattern matching in tests.
4. **ethos-zero: Meaning maps to stale name** — datomic::MeaningValue vs
   datomic::Meaning. Does not block this port (Meaning not used).
