# A Duration before the intrinsic

Proposed short-term Ethos line for the living's review:

> Until Duration is an Ethos intrinsic, the Flow meta contract declares `Duration.Integer` in its own library, measured in milliseconds. When the intrinsic lands, the local declaration is removed and its consumers use the intrinsic.

This records the temporary representation authorized for the retirement hook deadline; it does not set a deadline value.
