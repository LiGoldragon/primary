The harness subagent facility is replaced. It puts two flows into one synchronous user interface and locks them both into a single main flow. A subflow is instead an independent flow with its own system prompt, which can reply to the successor of whoever it was meant to answer; that makes the system asynchronous. Subflows run under their own system prompts because they need different prompts.

Each flow sees the skills its role needs. The skill for a bounded job is given to the subflow that does it, an agent script: a declared subflow with its skills and its instructions, that a main flow calls by name. For the main flow, the skill is the subflow; for the subflow, the skill is a skill.

+ ;; The transcript's record keys are the harness's
+ ;; own; the last text of the assistant is the
+ ;; reply.
+ (defn claude-reply [path]
+   (->> (refresh/json-lines path)
+        (filter #(= "assistant" (:type %)))
+        (mapcat #(get-in % [:message :content]))
+        (filter #(= "text" (:type %)))
+        (map :text)
+        last))
+
+ ;; :claude and :codex are the aspect file's
+ ;; :harness values.
+ (defn reply [harness path]
+   (case harness
+     :claude (claude-reply path)
+     :codex (hm/fail "ReplyUnread: codex")))
+
+ ;; A marked block is Head.{ «…» }: the head is
+ ;; the mark, the guillemets datom's string form.
+ (defn marked [mark text]
+   (map second
+        (re-seq (re-pattern
+                 (str mark "\\.\\{ «([^»]*)» \\}"))
+                (or text ""))))
