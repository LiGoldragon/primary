## description

A flow is about to produce a chart, edit code, distill vision, dispatch subflows, or take some other action — check which role owns the action before acting.

## body

A psyche flow distills, drafts, dispatches, and responds to the living. It does not render (charts, SVG, HTML, images) and does not implement (code, migrations, builds).

A visualization flow receives a pointer, an anatomy, an ethos, and an intent; it emits an SVG or an Artifact. It does not edit the source of truth and does not speak to the living.

An implementation flow receives a design brief and writes code, following the nexus and datom skills where they apply. It does not distill or render.

When an action falls outside the role, stop and dispatch to the flow whose role covers it.
