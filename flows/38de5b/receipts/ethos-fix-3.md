## Change (src/generation.rs)

- **Archive bounds.** In a Signal, a position that reaches its owner by any path, `Vector` included, carries `#[rkyv(omit_bounds)]`. A struct or enum with such a position states `serialize_bounds(__S: Writer + Allocator, __S::Error: Source)`, `deserialize_bounds(__D::Error: Source)` and `bytecheck(bounds(__C: ArchiveContext, __C::Error: Source))` once. This covers `Vector<Self>`, not only the boxed positions. Every cycle of bounds loses its edges, so the trait solver terminates.
- **Boxing only where a cycle closes.** A position is boxed when it names a struct or enum that reaches the owner by value and is declared no later than the owner. It may name it through aliases, Option and Result, but not Vector. Every by-value cycle has such an edge. `Twin.{ Twig Twig }` is now unboxed, and only `Twig`'s `Grow` is boxed.
- **Bare variants.** A bare variant that names a declared type now counts when reaching and boxing. Before, `Knot.[ End Loop ]  Loop.{ Knot }` produced an infinitely sized type.
- **rustfmt.** Every generated struct, enum and alias now carries its own `#[rustfmt::skip]`. Before, an enum emitted after its inline payloads had none. This surfaced once tree-types carried the Signal `cfg_attr`. src/error.rs, src/ethos-zero.rs and 4 fixture outputs gained only skip lines.
- README: the boxing paragraph now states both rules.
